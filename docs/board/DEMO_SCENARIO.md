# 게시판 시연 시나리오 (5분)

> 기획 초안(`drafts/PRODUCT_DRAFT.md` 5장)을 확정 계약(API 4장)과 평가·시연 리뷰(`drafts/REVIEW_GEMINI.md`)에 맞춰 줄인 버전.

## 준비물
1. 시드(`seed_board_demo.sql`) 적재, 백엔드·프론트 실행
2. **창 A = 일반 브라우저**(작성자 게스트), **창 B = 다른 브라우저 또는 시크릿 창**(다른 게스트). 같은 브라우저의 시크릿 창 두 개는 저장소를 공유해 토큰이 덮어써진다.
3. 관리자 로그인된 별도 창(`/admin/login`)
4. 창 A 소유 ENDED 게임 1개(RECORD 미작성, TASK-005B 이후)
5. 보조 탭 3개: 검색 `EXPLAIN` 캡처, `403` 응답 캡처, 테스트 결과 목록
6. 붙여넣을 문구(제목, 본문, 댓글)를 메모장에 미리

## 진행
| 시간 | 창 | 할 것 (조작 최소화) | 평가 포인트 |
| --- | --- | --- | --- |
| 0:00-0:30 | A | 홈의 랭킹 + 인기글 3건 → "커뮤니티" | 게임과 커뮤니티가 한 서비스 |
| 0:30-1:20 | A | 고정 공지 확인 → 인기순 정렬 → 2쪽 → "제목+내용" 검색 1회 → 엔딩 인증 탭 + 업종 필터 → (보조 탭) EXPLAIN 한 장 | Pageable, 동적 검색, 정렬 화이트리스트, trgm 인덱스 |
| 1:20-2:20 | A | 엔딩 화면 "엔딩 인증하기" → 제목 비우고 등록(400) → 붙여넣고 등록(201) → 엔딩 카드 → "공유 카드 보기"(Thymeleaf)에 인증글 링크 | `@Valid`, 서버가 채우는 스냅샷, React↔Thymeleaf |
| 2:20-3:20 | A, B | B가 상세 열기(조회수 +1, 새로고침해도 그대로) → A·B 둘 다 수정 화면 → A 저장 → B 저장 409 안내 → A가 댓글, B가 그 댓글에 대댓글(대댓글엔 답글 버튼 없음) → B 좋아요 | 하루 1회 조회수, 낙관적 락, 1단계 대댓글, 멱등 좋아요 |
| 3:20-4:20 | B, 관리자 | B 화면엔 수정·삭제 버튼 없음(보조 탭 403 캡처) → B가 **대댓글이 달린 A의 루트 댓글**을 신고 → 관리자 신고 처리 → 303 + 플래시 → B 새로고침 시 "표시할 수 없는 댓글입니다." | 권한 분리, Spring Security 세션, CSRF, PRG |
| 4:20-5:00 | A | 글 삭제(soft) → 목록에서 사라지고 엔딩 화면에 다시 "엔딩 인증하기"가 보임(재작성은 생략) → 테스트 결과 탭으로 마무리 | soft delete, 부분 유일 인덱스, Testcontainers |

## 실패하기 쉬운 지점
- 조회수: 무토큰 조회는 오르지 않는다. 반드시 토큰이 있는 창 B로 "처음 열 때 +1 → 새로고침해도 그대로"를 보여준다.
- 자리표시자: 답글이 없는 댓글을 숨기면 목록에서 그냥 사라진다. 신고 대상은 대댓글이 달린 루트 댓글로.
- 프론트 실제 모드: 시연 전에 좋아요 204 처리, 409 코드별 안내, 무토큰 상세에서 토큰 자동 발급이 없는지 확인(TASK-005C 어댑터).
- 레이트 리밋: 리허설 직후 바로 시연하면 분당 글 3건 제한에 걸릴 수 있다. 1분 쉬고 시작.

## TASK-005B(엔딩 작업)가 발표 전에 안 끝나면
- 1:20-2:20 구간을 "TIP 글 작성 + 400 검증"으로 바꾼다.
- RECORD 목록 필터와 상세 카드는 005A 시드(SQL로 넣은 ENDED 게임 3개 + RECORD 3건)로 라이브 시연할 수 있다. 작성만 막혀 있다.
- 설명 멘트: "게임 도메인과의 결합은 읽기 전용 포트 하나로 격리했고, 트리거·부분 유일 인덱스·화면은 먼저 만들어 두어 엔딩 작업이 병합되면 차단만 풀면 됩니다."

## 채점자 질문 대비 ("싱글 게임에 왜 게시판?")
- "싱글 게임이라도 다른 사장님과 전략을 비교하고 회고하는 게 재미의 큰 부분이라, 숫자만 보이는 랭킹을 넘어 공략과 엔딩 후기를 나누는 커뮤니티를 붙였습니다."
- "그냥 자유게시판이 아니라, 끝난 게임의 실제 상권·업종·수익을 서버가 검증해 스냅샷으로 고정하는 엔딩 인증글로 게임과 연결했습니다."
- 차별점 3개: ① 위조 불가 엔딩 인증(서비스 검증 + DB 트리거 이중 방어) ② 실제 서울 상권·업종 코드 필터 + 한국어 부분 검색 인덱스(pg_trgm) ③ 동시성 설계(멱등 좋아요, 낙관적 락, 하루 1회 조회수, 동시 대댓글 교착 방지까지 실측 검증)
