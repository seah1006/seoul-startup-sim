## 1. 지금 화면이 AI 템플릿처럼 보이는 이유 (걷어낼 것)
1. 크림 배경(#f5f5ef) + 세이지 초록 + 둥근 큰 카드(radius 24px 안팎) + 연한 테두리 조합
2. 모든 섹션 위의 작은 자간 넓은 라벨(`.eyebrow`, 16곳): "서울 창업 시뮬레이터", "진짜 데이터, 나만의 이야기", "상권 리포트" 등
3. 추상 슬로건 히어로: "당신의 가게가 서울의 이야기가 되도록." + "↗" 화살표 버튼 + "01 02 03" 단계 줄
4. 같은 모양 카드 3개 나란히(랭킹/데이터 소개/인기글), 의미 없는 사선 무늬 배경(지도 로딩 영역)
5. 모든 숫자가 본문 글꼴, 표 대신 카드, 여백이 과하게 넓은 중앙 정렬

## 2. 새 방향: "골목 장부"
게임의 실체(동네 가게 하나를 분기마다 결산하는 일)를 화면 언어로 쓴다. 가게 **간판**, 사장님의 **장부·영수증**, **실제 지도**.

### 토큰 (CSS 변수로 `:root`에 정의하고 하드코딩 색 제거)
| 이름 | 값 | 쓰임 |
|---|---|---|
| `--paper` | `#fbfaf6` | 배경(거의 흰 종이). 크림 금지 |
| `--ink` | `#1d1d1b` | 본문·선 |
| `--ink-2` | `#5b5a55` | 보조 글 |
| `--rule` | `#d9d6cc` | 장부 괘선 |
| `--sign` | `#c8102e` | 간판 빨강. 주 버튼, 강조, 적자, 도장 |
| `--sign-ink` | `#ffffff` | 빨강 위 글자 |
| `--ok` | `#0b6e4f` | 흑자(초록은 숫자에만) |
| `--marker` | `#ffe14d` | 형광펜 밑줄(핵심 숫자 1~2개에만) |
| `--radius` | `2px` | 모서리. 카드 둥글리기 금지(최대 4px) |

### 글꼴 (Google Fonts, 한 번만 import)
- 본문: `Pretendard`(CDN `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css`) 또는 Noto Sans KR 유지. 굵기 400/600/800만.
- 간판·가게 이름·큰 제목: `Black Han Sans` (브랜드, 가게 이름, 페이지 제목에만. 본문 금지)
- 금액·수치: `IBM Plex Mono` + `font-variant-numeric: tabular-nums`, 오른쪽 정렬

### 구성 원칙
- 카드 대신 **괘선(1px `--rule`)과 굵은 구분선(2px `--ink`)** 으로 영역을 나눈다. 그림자 금지(지도 위 팝업만 예외).
- 라벨은 `.eyebrow` 대신 표의 `th`나 `dt`처럼 왼쪽 정렬 보통 크기 굵은 글로. 자간 벌리기 금지. 꼭 필요 없는 라벨은 삭제.
- 화살표 장식(↗, →) 삭제. 버튼 글은 동사로 짧게("창업하기", "다음 분기로").
- 주 버튼: `--sign` 배경, 흰 글, 각진 모서리. 보조 버튼: 흰 배경 + `--ink` 1.5px 테두리.
- 폭: 본문 최대 1120px, 왼쪽 정렬. 데스크톱에서 지도·리포트 2단은 유지.

## 3. 화면별 지시
1. **헤더**: 간판 띠. `--ink` 배경 전체 폭, 왼쪽에 `서울 사장님`(Black Han Sans, 흰색), 오른쪽 메뉴(흰색 글). 부제 "서울에서 시작하는 나의 가게" 삭제. "실제 데이터 모드" 배지는 작은 테두리 글로(목 모드일 때만 눈에 띄게 노란 배경).
2. **홈**: 슬로건 히어로 삭제. 위쪽에 한 줄 소개 + 실제 수치:
   - 제목(Black Han Sans): `서울 골목에 가게 하나 차려 보기`
   - 한 줄: `서울시 상권 1,650곳의 실제 매출·점포·유동인구로 분기마다 결산합니다.`
   - 주 버튼 `창업 시작`, 보조 링크 `이어서 하기`(저장된 게임 있을 때)
   - 그 아래 2단: 왼쪽 **오늘의 랭킹 표**(순위/사장님/가게/동네/결과, 숫자 mono), 오른쪽 **커뮤니티 최근 글 목록**(괘선 리스트)
   - 맨 아래 작은 글씨 각주로 데이터 출처(서울 열린데이터광장 상권분석서비스, 공공데이터포털 소상공인 상가정보). "진짜 데이터, 나만의 이야기" 카드 삭제. "01 02 03" 삭제.
3. **사장님 만들기(/new)**: 후보 카드를 **능력치 표**로(행=후보, 열=요리·서비스·경영·마케팅·체력·인맥·합계, 선택 행 강조). 출발점·집중 능력치는 각진 토글 버튼.
4. **동네 찾기**: 지도 왼쪽, 오른쪽은 리포트를 **정의 목록(dl)** 장부 형태로(유동인구 / 점포·프랜차이즈 / 개업률·폐업률 / 분기 매출). 경쟁 점포는 거리순 표(이름 | 거리 m, mono). 지도 로딩 실패 영역의 사선 무늬 삭제 → 단색 + 안내 글. 지도 폴리곤·반경 원 색은 `--sign` 계열(선택 영역 채우기 투명도 0.12).
5. **분기 결산(ResultCard)**: **영수증**. 위아래 지그재그 또는 점선 테두리, `IBM Plex Mono` 금액 오른쪽 정렬, 항목(매출, 방문객, 객단가, 비용 항목들, 잔액)을 줄 단위로. 순이익은 맨 아래 굵게 + 흑자면 `--ok`, 적자면 `--sign`. 오른쪽 위에 회전된 **도장**(테두리 원, `흑자`/`적자`, 빨강, 약간 투명). 동네 반응은 영수증 아래 짧은 손글씨 느낌 없이 일반 리뷰 리스트(별점은 ★ 문자 유지).
6. **운영 결정 폼**: 장부 입력란처럼 라벨 왼쪽, 입력 오른쪽 2열 그리드(모바일 1열).
7. **랭킹·게시판**: 표/괘선 리스트. 랭킹 모바일 카드형은 유지하되 각진 모양.
8. **엔딩·공유 페이지** `backend/src/main/resources/templates/share/game.html`(Thymeleaf, 공개 링크): 같은 토큰으로 영수증 형태 결산 + 도장. 관리자 화면(`templates/admin/**`)은 손대지 않는다.
9. 푸터: 한 줄 각주(데이터 출처 + "게임 속 반응과 이벤트는 가상입니다").
