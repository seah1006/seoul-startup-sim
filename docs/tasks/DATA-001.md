## 조사 대상과 질문

### A. 서울시 상권분석서비스 (서울 열린데이터광장)
대상 데이터셋: 영역-상권, 추정매출-상권(OA-15572), 점포-상권(OA-15577), 길단위인구-상권, 직장인구-상권. (데이터셋 번호는 직접 찾아 확인)

각 데이터셋마다:
1. Open API 서비스명, 요청 인자(분기 코드 등), 응답 필드 목록과 의미
2. 분기 하나당 행 수, 제공 분기 범위(가장 이른 분기, 최신 분기)
3. 파일 다운로드(CSV/SHP/zip) 제공 여부와 용량

특히 답할 것:
- **추정매출 `THSMON_SELNG_AMT`(당월 매출 금액)의 기준 기간**: 분기의 한 달인지, 분기 합계인지, 월평균인지. 공식 설명, 다른 필드(요일별, 시간대별 합)와의 합계 관계 등으로 검증.
- **영역-상권의 좌표계**: 좌표 값 범위, 제공되는 SHP의 .prj, 공식 설명으로 EPSG 코드 확정 (예: 5181, 5174, 4326 등). 영역(폴리곤)이 API로 오는지, 중심점만 오는지, 폴리곤은 SHP 파일로만 오는지.
- **상권 수와 상권 구분**(골목상권, 발달상권, 전통시장, 관광특구 등) 값 목록
- **서비스 업종 코드(CS...) 전체 목록**과 이름, 개수
- **결측**: 최신 분기 기준으로 (상권 × 업종) 조합 중 매출 데이터가 있는 비율. 점포 데이터는 있는데 매출이 없는 조합의 비율.
- **2024년 표준단위구역 변경**: 2023년 분기와 최신 분기의 상권 코드 목록 비교 (같은 코드 개수, 사라진 코드, 새 코드)
- **임대 시세**: 상권분석서비스 또는 서울 열린데이터광장에서 임대료(임대시세) 데이터를 API나 파일로 받을 수 있는지

### B. 소상공인시장진흥공단 상가(상권)정보 API (공공데이터포털)
Base URL: `https://apis.data.go.kr/B553077/api/open/sdsc2`
1. `storeListInRadius`, `storeListInDong`, `storeListByDate`, `smallUpjongList`의 실제 요청 인자, 응답 필드, 페이지 크기 최대값, 응답 형식(JSON 가능 여부)
2. 서울 전체 상가업소 수 추정 (행정동 몇 개 샘플 또는 다른 방법), 전체 적재에 필요한 호출 수와 일일 트래픽(10,000)으로 며칠 걸리는지
3. 대량 적재 대안: 소상공인시장진흥공단의 **파일 데이터(CSV) 다운로드**가 있는지, 어디서 받는지, 갱신 주기
4. 업종 소분류 코드 체계(현재 개수)와 **서울시 서비스업종 코드(CS)와 매핑 가능성**: 이름 기준으로 1:1, N:1, 매핑 불가 비율을 실제로 대조해서 추정. 매핑 표 초안을 CSV로.
5. 좌표 형식(경도, 위도 필드명, 좌표계)
