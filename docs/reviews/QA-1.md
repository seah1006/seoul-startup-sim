# QA-1: 서울 사장님 프론트엔드 목 모드 QA 보고서

- **점검 일시**: 2026-11-18
- **대상**: `http://127.0.0.1:5173` (React 프론트엔드, 목 모드)
- **해상도**: 데스크톱 `1280x900`, 모바일 `390x844`
- **요약**: 핵심 게임 루프(사장님 생성 → 동네/업종 선택 → 분기 운영/결산/전환점 → 8분기 엔딩 및 4분기 매각 → 랭킹)와 게시판 CRUD(목록, 상세, 좋아요, 댓글·대댓글, 신고 모달, 작성/수정/삭제, 내 글)는 데스크톱·모바일 모두 가로 넘침 없이 동작한다. 다만 목 모드에서의 `/share/{gameId}` 500 오류, RECORD 필터의 개발자용 원시 코드 노출, 잘못된 `gameId` 오류 문구, 목 데이터 `isMine` 불일치 등이 확인되었다.

---

## 높음 (High)

해당 없음. (핵심 창업·운영·엔딩·게시판 플로우를 막는 치명적 결함은 발견되지 않음)

---

## 중간 (Medium)

### 1. 엔딩·인증글의 "공유 페이지" / "공유 카드 보기" 이동 시 HTTP 500 발생 (목 모드)
- **화면·크기**: 엔딩 화면(`/games/1`, `/games/2`), 게시글 상세(`/board/posts/2`, `/board/posts/31`), `1280x900` · `390x844` 공통
- **재현 단계**:
  1. 8분기 엔딩 또는 4분기 매각 엔딩에 도달한다.
  2. 엔딩 카드 하단의 `공유 페이지` 링크(`/share/2`)를 클릭한다. (또는 RECORD 게시글 상세에서 `공유 카드 보기` 클릭)
- **기대**: 목 모드에서도 프론트엔드 안내/미리보기 화면을 보여 주거나, 백엔드 전용 경로라면 목 모드에서 비활성화/안내 처리한다.
- **실제**: 브라우저가 `/share/2`로 이동한 뒤 `페이지가 작동하지 않습니다. HTTP ERROR 500` 오류 화면이 표시된다.
- **캡처**: `docs/reviews/qa-1/01-share-page-500.png`

### 2. 게시판 "엔딩 인증" 탭 필터가 업종·상권 이름 대신 원시 코드 입력을 요구함
- **화면·크기**: 게시판 목록(`/board?category=RECORD`), `1280x900` · `390x844` 공통
- **재현 단계**:
  1. `/board`에서 `엔딩 인증` 카테고리 탭을 클릭한다.
  2. 검색 폼에 추가되는 필터 입력칸을 확인한다.
- **기대**: 일반 사용자가 이해할 수 있도록 업종 드롭다운(예: `커피-음료`)과 상권 이름 선택/검색 UI를 제공한다.
- **실제**: `업종 코드 (예: CS100010)`, `상권 코드 (예: 3110123)` 텍스트 입력칸이 노출되어, 코드를 모르는 사용자는 필터링할 수 없다.
- **캡처**: `docs/reviews/qa-1/04-board-record-raw-codes.png`

### 3. 존재하지 않는 `gameId`로 엔딩 인증글 작성 진입 시 오인하기 쉬운 네트워크 오류 문구 표시
- **화면·크기**: 엔딩 인증글 작성(`/board/write?category=RECORD&gameId=99999`), `1280x900`
- **재현 단계**:
  1. 주소창으로 `/board/write?category=RECORD&gameId=99999`에 직접 접근한다.
- **기대**: `게임을 찾을 수 없습니다` 등 대상을 찾지 못했다는 안내와 돌아가기 동선을 표시한다.
- **실제**: `서버 연결에 실패했습니다. 잠시 후 다시 시도해 주세요.` 경고가 표시된다.
- **캡처**: `docs/reviews/qa-1/03-record-invalid-gameid-error.png`

### 4. 목 데이터 일부 게시글의 작성자명과 `isMine` 상태가 불일치함
- **화면·크기**: 게시글 상세(`/board/posts/2`), 내 글(`/board/me`), `1280x900`
- **재현 단계**:
  1. `/board`에서 `가상 구름모래 찻집 · 첫 창업 회고`(작성자 `연습 사장님 2`)를 열어 상세 화면으로 이동한다.
  2. `/board/me`로 이동해 목록을 확인한다.
- **기대**: 타인(`연습 사장님 2`, `연습 사장님 5`)의 글에는 `게시글 신고` 버튼이 보이고 `내 글`에는 포함되지 않거나, 내 글이라면 작성자명이 `연습 사장님`으로 일치해야 한다.
- **실제**: 작성자는 `연습 사장님 2`로 표시되지만 `isMine: true`로 처리되어 `수정`/`게시글 삭제` 버튼만 노출되고 `게시글 신고` 버튼이 없으며, `/board/me`에도 함께 노출된다.
- **캡처**: `docs/reviews/qa-1/05-post2-ismine-mismatch.png`

## 낮음 (Low)

### 5. 존재하지 않는 경로(404) 화면에 안내 문구/제목이 없음
- **화면·크기**: 알 수 없는 경로(`/some-nonexistent-page`), `1280x900`
- **재현 단계**: 존재하지 않는 URL 경로로 이동한다.
- **기대**: `페이지를 찾을 수 없습니다` 등 상태 안내 문구와 함께 홈 이동 링크를 제공한다.
- **실제**: 본문에 안내 문구 없이 `홈으로 돌아가기` 링크만 단독으로 표시된다.
- **캡처**: `docs/reviews/qa-1/02-404-empty-message.png`

### 6. 분기 결산 카드 출처 및 기록 차트 X축에 원시 분기 코드(`20231`) 노출
- **화면·크기**: 분기 결산 카드 및 `기록` 탭(`/games/1`), `1280x900` · `390x844`
- **기대**: `2023년 1분기` 등 사람이 읽기 쉬운 형식으로 통일해 표시한다.
- **실제**: 결산 카드 상권 소식 출처(`출처: 서울시 상권분석서비스 20231 (목 예시, 실제 조회 아님)`)와 `기록` 탭의 순이익 차트 라벨(`20231`, `20232`)에 원시 코드가 그대로 출력된다.

### 7. 랭킹 화면에서 날짜 변경 시 목 데이터가 날짜별로 필터링되지 않음
- **화면·크기**: 랭킹(`/rankings`), `1280x900`
- **재현 단계**: 오늘 엔딩을 1건 이상 만든 뒤 `조회 날짜 (최근 7일)` 셀렉트 박스를 `2026-11-17` 등 이전 날짜로 변경한다.
- **기대**: 해당 날짜의 기록(없으면 빈 상태 안내)을 표시한다.
- **실제**: 날짜를 변경해도 당일 생성된 랭킹 목록이 동일하게 표시된다.

### 8. 댓글 대댓글 목록이 단일 아코디언으로 동작해 다른 답글 펼침 시 기존 답글이 접힘
- **화면·크기**: 게시글 상세(`/board/posts/2`), `1280x900`
- **재현 단계**: 첫 번째 댓글의 `답글 1개 보기`를 눌러 펼친 뒤, 세 번째 댓글의 `답글 1개 보기`를 누른다.
- **기대**: 여러 댓글의 답글을 동시에 펼쳐 비교할 수 있거나, 의도된 아코디언이라면 상태 변화가 자연스러워야 한다.
- **실제**: 새 댓글의 답글을 열면 앞서 열어 둔 다른 댓글의 답글 영역이 자동으로 닫힌다.

### 9. 영문 디자인 라벨 노출
- **화면·크기**: 홈, `/new`, `/games/:id`, `/rankings`, `/board` 상단
- **실제**: `SEOUL STARTUP SIMULATOR`, `STEP 01 / YOUR OWNER`, `QUARTER REPORT`, `YOUR NEXT MOVE`, `OWNERS RANKING`, `SEOUL STARTUP COMMUNITY` 등의 영문 서브헤더가 사용되고 있다. (디자인 콘셉트 범위이나 한국어 UI 일관성 점검 시 참고)

## 정상 확인 항목 (요약)
- **카카오맵 미로드 대체 UI**: `127.0.0.1` 환경에서 지도 로드 실패 시 안내 문구와 `선택 상권 중심점에 위치 지정` 대체 버튼이 정상 동작해 창업 진행에 막힘이 없었다.
- **금액·가상 반응·출처 표기**: `1억 6,564만 원`, `1,383만 원`, `14,100 원` 등 금액 단위가 일관적이며, `목 모드` 안내, 데이터 출처, `동네 반응은 게임 속 가상 반응입니다` 표기가 모두 포함되어 있다.
- **XSS 방어·유효성 검증·상태 유지**: 게시글 본문의 `<script>alert(1)</script>`가 일반 텍스트로 안전하게 렌더링되었고, 빈 제목 검증, 중복 신고 409 안내, 대댓글 없는 삭제 vs 답글 있는 삭제 자리표시자(`표시할 수 없는 댓글입니다.`), 새로고침 후 게임/게시판 쿼리 상태 복원이 정상 동작했다.
- **모바일(`390x844`) 레이아웃**: 홈, 사장님 생성, 동네 찾기, 결산, 전환점, 엔딩, 랭킹, 게시판 목록/상세/작성/내 글 모두 가로 스크롤 없이 정상 배치되었다.
