# 서울 창업 시뮬레이터 (seoul-startup-sim)

서울의 실제 상권 데이터로 돌아가는 창업 시뮬레이션 웹 게임입니다.

지도에서 서울의 실제 상권을 골라 가게를 열면, 그 상권의 실제 추정매출, 점포 수, 개폐업률, 유동인구와 주변에 실제로 있는 경쟁 점포 데이터로 매달 매출과 생존 여부가 계산됩니다.

> 대학 프레임워크 강의 기말과제이자 개인 포트폴리오 프로젝트입니다. (진행 중)

## 핵심 아이디어

- **데이터를 빼면 게임이 성립하지 않는 구조**: 시장 규모, 경쟁자, 위기 확률이 모두 실제 공공데이터에서 나옵니다.
- **실제 시간 흐름을 따라가는 게임**: 게임 시간은 실제 분기 순서(2021년 이후)를 따라가고, 분기가 바뀌면 다음 분기의 실제 데이터가 반영됩니다.
- **재현 가능한 시뮬레이션**: 시드, 플레이어 선택, 데이터 버전이 같으면 결과가 항상 같습니다.

## 백엔드에서 다루는 문제

1. **외부 API 수집 파이프라인**: 속도 제한, 재시도와 백오프, 증분 수집, 수집 이력, 원본과 정규화 데이터 분리
2. **대량 적재**: 상가업소 데이터 적재 방식별 성능 비교 (JPA `saveAll` / JDBC batch / PostgreSQL `COPY`)
3. **위치 기반 조회**: PostGIS 반경 검색, 상권 영역 판정, 공간 인덱스
4. **데이터 버전 관리**: 분기별 갱신이 있어도 진행 중인 게임 결과가 바뀌지 않도록 게임마다 데이터 버전 고정
5. **턴 진행 정합성**: 트랜잭션, 락, DB 제약조건으로 같은 달이 두 번 진행되는 문제 방지

## 기술 스택 (예정)

| 영역 | 기술 |
| --- | --- |
| Backend | Java, Spring Boot, Spring Data JPA, JdbcTemplate, Spring Security (카카오 OAuth2), Resilience4j, Flyway |
| DB | PostgreSQL + PostGIS |
| Frontend (게임) | React (Vite), 카카오맵 JavaScript SDK |
| 서버 렌더링 화면 (관리자, 공유) | Thymeleaf |
| Test | JUnit 5, WireMock |

## 구조 (예정)

```
[React 게임 화면] ──/api/**──▶ ┐
                               │  Spring Boot
[브라우저] ──/admin/**, /share/**▶│   ├ @RestController  게임 API (JSON)
                               │   ├ @Controller      Thymeleaf (관리자, 공유 페이지)
                               │   ├ @Service         게임 엔진, 수집 로직
                               │   ├ @Repository      PostgreSQL + PostGIS
                               │   └ @Scheduled       외부 데이터 수집기
                               ┘          │
                                          ▼
                     서울 열린데이터광장 / 공공데이터포털 / 카카오
```

게임 요청 처리 중에는 외부 API를 호출하지 않습니다. 외부 데이터는 배치로 수집해 DB에 저장하고, 게임은 DB만 읽습니다.

## 사용 데이터와 출처

| 데이터 | 제공 | 용도 |
| --- | --- | --- |
| 서울시 상권분석서비스 (영역, 추정매출, 점포, 길단위인구, 직장인구) | 서울특별시, 서울신용보증재단 / 서울 열린데이터광장 | 상권 영역, 시장 규모, 개폐업률, 유동인구 |
| 소상공인시장진흥공단 상가(상권)정보 API | 소상공인시장진흥공단 / 공공데이터포털 | 실제 점포 위치와 업종 (경쟁 점포) |
| 카카오맵 API | 카카오 | 지도 표시 |

- 서울시 상권분석서비스 데이터는 공공누리 제1유형(출처표시) 조건에 따라 이용합니다.
- 서비스 화면에도 데이터 출처를 표기합니다.
